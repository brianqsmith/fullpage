Supplemental docs
=================

This folder contains generated documentation and validation artifacts that were
created while preparing the handoff package but were not part of the core
developer copy.

- `workspace/handoff-build/docx-final/01_FUNCTIONAL_REQUIREMENTS.pdf` is the
  final PDF render used to visually inspect the Word requirements document.
- `workspace/handoff-build/docx-qa/01_FUNCTIONAL_REQUIREMENTS.pdf` is an
  earlier QA render retained for completeness.
- `workspace/handoff-build/lint-final.json` is the final documentation lint
  result captured during package preparation.

The original Firefox browser profile files remain excluded because they are
runtime cache/profile state rather than project documentation.
